# Voicer

Монтаж голосовых записей вместе с ИИ. Voicer распознаёт речь пословно и вычёркивает «э-э», повторы, дубли
и длинные паузы. Остальное правите сами в браузере или поручаете Claude Code / Codex. Всё работает на вашем
компьютере, без облака.

## Запуск (Windows)

1. **Code → Download ZIP**, распакуйте.
2. Дважды щёлкните **`start.bat`**. Первый запуск сам всё установит (~1 ГБ, с видеокартой NVIDIA ~3 ГБ)
   и откроет http://127.0.0.1:8765
3. Перетащите запись в окно или откройте пример **example-3d**.

Видеокарта NVIDIA ускоряет распознавание, но не обязательна. macOS/Linux: `./start.sh` (не проверялось).

## С Claude Code или Codex

Откройте папку Voicer в Claude Code или Codex и напишите: **«обработай последний проект в Voicer»**.
Скилл `voicer` уже в репозитории, правки сразу видны в браузере.
