# Монтаж речи в Voicer

Пользователь загружает запись в веб-интерфейс (`start.bat` → http://127.0.0.1:8765) или просит тебя
импортировать файл. Ты читаешь транскрипт с пословными таймкодами, решаешь, что вырезать и какие паузы
поправить, и применяешь правки командами. Интерфейс опрашивает проект раз в 1,5 с: пользователь сразу видит
твои правки и может отменить любую.

## Запуск команд

Из корня Voicer (папка с `pyproject.toml`; этот файл лежит в `<корень>/.claude/skills/voicer/` или
`<корень>/.agents/skills/voicer/`):

```bash
.venv/Scripts/python.exe -m voicer <команда> [-p ID] ...   # Windows
.venv/bin/python -m voicer <команда> [-p ID] ...           # macOS / Linux
```

Ниже `voicer` означает эту команду. Если `.venv` нет, Voicer не установлен: попроси запустить `start.bat`
(`./start.sh`), он установит всё сам.

`-p` можно не указывать: тогда берётся последний изменённый проект. Вывод в UTF-8.
Не правь `projects/*/project.json` руками: только через `voicer edit`, иначе ломается отмена и история.

## Рабочий цикл

1. `voicer list`: найти проект (или `voicer import <путь> [--lang ru] [--script сценарий.txt]`).
   Несколько файлов или папка (`voicer import <папка>` / `voicer import a.ogg b.ogg …`) — **пак**: файлы
   склеиваются по порядку имён (0,5 с тишины между ними), ранние дубли сразу вычёркиваются (причина `retake`).
   Стыки файлов видны в заголовке `voicer show` («пак из N файлов»). Распознавание длинной записи идёт
   минуты (на процессоре дольше): запускай импорт в фоне или с большим тайм-аутом.
2. `voicer stats`: длительности, паузы, **заметки пользователя** (`# ЗАМЕТКИ ПОЛЬЗОВАТЕЛЯ`) и история.
   Заметки — это прямые пожелания, выполнить их в первую очередь.
3. `voicer show`: транскрипт. Для длинных записей листать кусками: `--range 0-400`, `--time 2:00-4:00`.
   - `N:слово`: токен №N; `~~N:слово~~`: уже вырезан (с причиной в конце вывода);
   - `N:~0.4s`: озвученный звук между словами, который Whisper не записал (заминка «э-э», вдох, кашель, шум);
   - `‖1.2‖`: пауза после токена в секундах; `‖1.2→0.30‖`: пауза задана вручную;
   - `слово?`: низкая уверенность распознавания (возможна ошибка, проверь по смыслу).
4. Решить правки и применить одним пакетом, с причинами (комментарий после `#` — для себя):

   ```bash
   voicer edit -p ID -f - <<'EOF'
   cut 41-44 repeat        # «программа должна, программа должна» → оставить последний дубль
   cut 57 filler
   keep 12                 # «вот» здесь значимое, не паразит
   pause 88 1.2            # пауза перед новой темой
   set max_pause 0.45
   EOF
   ```

   В PowerShell (heredoc там нет) — команды аргументами: `voicer edit -p ID "cut 41-44 repeat" "cut 57 filler"`,
   или большой пакет сохранить в файл (UTF-8) и выполнить `voicer edit -p ID -f правки.txt`.
   Пакет атомарный: при ошибке в любой строке не применяется ничего.
5. `voicer show --text`: перечитать итоговый текст и убедиться, что смысл и грамматика целы.
6. `voicer render [--format mp3|ogg|wav|flac|m4a]`: собрать результат, путь будет в выводе.
   При необходимости `voicer export srt|vtt|txt`.

## Команды правок (`voicer edit --help`)

- `cut <номера> [причина]`, где номера `12`, `12-15`, `3,7,9-11` (без пробелов внутри списка);
- `keep <номера>` | `keep all`: вернуть (автоправила больше не тронут эти токены);
- `pause <номер> <сек|auto>`: длина паузы после токена;
- `edge <номер> start|end <сек>` / `edge <номер> auto`: точный край вырезки токена (пользователь тянет края
  красных областей на таймлайне). Звук до заданного края остаётся целиком, соседнее слово подрезается;
- `cuttime 1:02.5-1:04 [причина]` / `uncuttime 1:02-1:05`: вырезать время (кашель внутри слова, шум);
- `fix <номер> <текст>`: исправить ошибку распознавания (влияет на текст и субтитры, не на звук);
- `set <ключ> <значение>`: `max_pause`, `max_pause_sentence`, `join_pause`, `lead`, `tail`,
  `crossfade_ms`, `lufs` (`off` — без нормализации), `format`; `set <ключ> default` — вернуть по умолчанию;
- `auto [fillers] [soft] [softall] [repeats] [sounds] | auto all`: автоправила. `fillers` — «э-э», «мм» и
  заминки; `soft` — «ну», «вот», «короче», «как бы», стоящие отдельно; `softall` — те же слова везде;
  `repeats` — повторы и оговорки; `sounds` — вдохи и прочие звуки. По умолчанию `fillers soft repeats`;
- `set voice_clean on|off` — галочка «Очистка голоса»: без неё не применяются ни параметры ниже, ни `lufs`
  (громкость и лимитер) — только монтаж.
- `studio` | `studio off`: включить галочку и пресет / выключить галочку. Параметры (как Auphonic):
  `denoise` (DeepFilterNet, дБ, 100 — всё), `dereverb` (эхо комнаты, 0..2), `gate` (дБ ниже речи; паузы и
  хвосты эха в тишину), `dehum` (0/50/60/auto), `highpass` (Гц), `deess` (дБ), `leveler` (0..1),
  `compress` (степень), `limit` (дБ). Каждый ключ можно менять через `set`. Музыку не трогаем: разделения
  источников нет;
- `reset`: убрать все правки. `voicer undo`: отменить последний пакет.
- `voicer retakes [--dry]`: найти дубли и вычеркнуть ранние, оставив поздний (около минуты на 10 минут
  записи на видеокарте). Каждая фраза между паузами распознаётся отдельно: Whisper часто не пишет повтор,
  а растягивает на него соседнее слово, и по транскрипту такой дубль не виден. Длинное растянутое слово при
  этом подрезается через `edge`, а спрятанные в нём слова позднего дубля дописываются через `fix`.
- `voicer reanalyze`: заново найти паузы и звуки по сигналу (без распознавания), правки сохраняются.
  Нужен, если пользователь говорит, что пауза есть, а в транскрипте её нет: Whisper часто растягивает слова
  на паузу, анализатор это исправляет.
- `voicer notes ["текст"]`: прочитать или записать заметки проекта; `voicer settings`: все настройки.

## Как решать

- **Повторы и фальстарты**: оставлять последний (обычно лучший) дубль, вырезать начатое и брошенное
  («мы пошли в ма- мы пошли в магазин» → режем первую попытку целиком).
  Если пользователь говорит, что слышит повтор, а в транскрипте его нет, — `voicer retakes --dry`: он найдёт
  дубли, спрятанные Whisper в растянутые слова (слово на 2–9 секунд — верный признак).
- **Слова-паразиты**: «э-э», «мм» режутся всегда. «Ну», «вот», «как бы», «типа», «короче», «значит» —
  только когда они не несут смысла («это значит, что…» оставить).
- **Заминки `~заминка`**: отдельный ровный звонкий звук (провал громкости до и после), который распознаватель
  при отдельной проверке не слышит как слово из текста. Режутся правилом `fillers`. Растянутые окончания слов
  («мыыы») слитны со словом и заминками не считаются — не резать.
- **Звуки `~`**: короткие (0.1–1 с) посреди фразы — обычно заминки, резать. Вдохи перед фразой можно оставить
  для естественности, если пользователь не просил иначе.
- **Паузы** сжимаются автоматически до `max_pause` (в фразе) и `max_pause_sentence` (после . ! ?). Ручной
  `pause` — для драматургии: смена темы, акцент.
- **Галлюцинации Whisper** в тишине и в конце записи: «Продолжение следует», «Субтитры сделал/создавал …»,
  «Редактор субтитров …», «Спасибо за просмотр». Если их нет в речи, вырезать с причиной `hallucination`.
- **Сценарий** (`voicer show --script`): если он есть, сверять с ним. Лишнее (оговорки, дубли) резать, ошибки
  распознавания исправлять через `fix`.
- Не перерезать: после правок речь должна звучать естественно. Если не уверен, спроси пользователя или опиши
  варианты.
- Резать можно только целые токены и интервалы времени; переставлять фрагменты Voicer не умеет.

В конце коротко скажи пользователю, что вырезано и почему (по группам: дубли, паразиты, паузы), сколько
длилось и стало, и где лежит готовый файл.
