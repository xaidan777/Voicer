# Voicer: руководство

Загружаете mp3/ogg/wav (или текст), Voicer распознаёт речь с таймкодом каждого слова и помечает
слова-паразиты, повторы, фальстарты, заминки и длинные паузы. Дальше правите вы (в браузере) или ИИ-агент
(Claude Code, Codex) и получаете готовый файл без мусора, с ровными паузами и нормализованной громкостью.

## Запуск

- **`start.bat`** (macOS/Linux: `./start.sh`): веб-интерфейс, откроется http://127.0.0.1:8765.
  Первый запуск сам ставит [uv](https://docs.astral.sh/uv/), Python 3.11 и библиотеки в папку `.venv`
  (около 1 ГБ, с видеокартой NVIDIA ещё около 2 ГБ библиотек CUDA).
- **`install.bat`**: переустановить или обновить библиотеки.
- **`voicer.cmd ...`**: командная строка (её же используют Claude Code и Codex).

Первое распознавание скачивает модель Whisper в папку `models/`: ~1,6 ГБ (`large-v3-turbo`) на видеокарте
NVIDIA, ~0,5 ГБ (`small`) на процессоре. Без видеокарты распознавание медленнее.

## Интерфейс

- **Сверху** — проект, отмена (↶), галочка **«Очистка голоса»**, формат, **«Обработать»** и «Скачать».
  Очистка голоса (шумоподавление, эхо, гейт, де-эссер, левелер) применяется только при включённой галочке.
- **Слева** — проекты. Файлы можно просто перетащить в окно. Правый клик по проекту — удалить.
  **«+ Пак»** — несколько записей в одну дорожку (по порядку имён файлов, между файлами 0,5 с тишины);
  дубли сразу вычёркиваются, остаётся поздний.
- **В центре** — транскрипт: клик по слову — слушать с этого места, Ctrl+клик — вырезать/вернуть,
  Shift+клик — выделить несколько, Del — вырезать выделенное, клик по паузе — задать её длину.
- **Таймлайн** под транскриптом: слова поверх волны, вырезанное затемнено, ниже — результат с местами
  склеек. Колесо — прокрутка, Ctrl+колесо — зум, перетаскивание мышью — выделить участок и вырезать его.
  Края красных (вырезанных) областей можно тянуть — так точно задаётся начало и конец вырезки; двойной клик
  по краю возвращает автоматическую границу, Esc во время перетаскивания — отмена.
  Пробел — воспроизведение выбранной дорожки («Исходник» / «Результат»), шкала «дБ» показывает тихие звуки.
- **Справа** — очистка речи (паразиты, заминки, повторы), паузы, параметры очистки голоса (в том числе громкость и лимитер), выход
  (кроссфейд) и раздел для Claude: заметки, команды, история.

## Как работать вместе с Claude Code или Codex

Откройте папку Voicer в [Claude Code](https://claude.com/claude-code) или
[Codex](https://developers.openai.com/codex), напишите пожелания в «Claude → заметки» и скажите в чате:
**«обработай последний проект в Voicer»**. Агент возьмёт скилл `voicer` (`.claude/skills/voicer`,
`.agents/skills/voicer`): прочитает транскрипт, вырежет лишнее и соберёт файл. Правки сразу появляются в окне
(плашка «Изменено (Claude)»), любую можно отменить.

## Что умеет

| | |
|---|---|
| Транскрибация | faster-whisper large-v3-turbo, таймкод каждого слова, автоопределение языка |
| Слова-паразиты | «э-э», «мм», «хм» всегда; «ну», «вот», «как бы», «типа», «короче» по выбору или на усмотрение Claude |
| Повторы | «мы мы пошли», «программа должна, программа должна…»: остаётся последний дубль |
| Фальстарты | «мы пошли в ма- мы пошли в магазин»: вырезается брошенная попытка |
| Дубли (пак) | несколько записей → одна дорожка; перезаписанные фразы и фальстарты вычёркиваются, остаётся поздний дубль. Каждая фраза распознаётся отдельно, поэтому находятся и повторы, которые Whisper не записал |
| Заминки | озвученные места, которые Whisper не записал, показаны как `〰 0.4с` |
| Паузы | сжатие до заданного максимума (отдельно внутри фразы и между предложениями), ручная длина любой паузы |
| Склейки | на тишине, с кроссфейдом; если нужна пауза длиннее исходной, она заполняется «тоном комнаты» из этой же записи |
| Громкость | нормализация по EBU R128 (по умолчанию −16 LUFS) |
| Экспорт | mp3, ogg (opus), wav, flac, m4a; txt; srt/vtt с таймингами результата или исходника |

## Командная строка

```
voicer import запись.mp3 [--lang ru] [--script сценарий.txt]
voicer import папка | a.ogg b.ogg ... [--no-retakes]   # пак: одна дорожка, ранние дубли вычеркнуты
voicer retakes [-p ID] [--dry]   # найти дубли и вычеркнуть ранние (около минуты на 10 минут записи)
voicer list
voicer show [-p ID] [--range 0-300] [--time 1:00-2:00] [--text]
voicer edit [-p ID] "cut 12-15 repeat" "pause 42 0.3" "set max_pause 0.4"
voicer auto [fillers soft repeats sounds | all]
voicer undo
voicer reanalyze            # заново найти паузы по сигналу, без распознавания
voicer render [--format mp3|ogg|wav|flac|m4a] [-o файл]
voicer export txt|srt|vtt|json [--orig]
voicer notes "текст"        # заметки для LLM
voicer stats
voicer serve | voicer mcp
```

Без `-p` команда работает с последним изменённым проектом. Полный список команд правок: `voicer edit --help`.

## Настройки монтажа

| ключ | по умолч. | смысл |
|---|---|---|
| `max_pause` | 0.15 | паузы внутри фразы длиннее этого сжимаются, с |
| `max_pause_sentence` | 0.5 | то же после . ! ? |
| `join_pause` | 0.12 | минимальная пауза на месте вырезанного |
| `lead` / `tail` | 0.25 / 0.5 | тишина в начале и в конце |
| `crossfade_ms` | 15 | кроссфейд на склейках |
| `lufs` | −16 | громкость результата, `off` — не трогать (только при «Очистке голоса») |

## Студийный звук

Обработка, похожая на Auphonic. Для новых проектов включена по умолчанию; блок «Студийный звук» в
интерфейсе (или `voicer edit studio` / `voicer edit "studio off"`) включает и выключает её:

| ключ | пресет | что делает |
|---|---|---|
| `denoise` | 100 | шумоподавление нейросетью DeepFilterNet3: сколько дБ шума убрать (100 — всё) |
| `dereverb` | 1.5 | подавление эха комнаты (реверберации), 0..2 |
| `gate` | 32 | гейт: глушит паузы и хвосты эха тише речи на столько дБ, как Auphonic |
| `dehum` | auto | гул электросети 50/60 Гц и гармоники (`auto` определяет сам) |
| `highpass` | 80 | срез низов: гул, стуки, «бубнение», Гц |
| `deess` | 6 | де-эссер: приглушает резкие «с», «ш», дБ |
| `leveler` | 0.6 | выравнивает громкость тихих и громких фраз, 0..1 |
| `compress` | 2 | мягкий компрессор |
| `limit` | −1 | лимитер: пики не выше −1 дБ, а громкость при этом доходит до `lufs` |

Всё работает локально, без интернета (модель шумоподавления ~10 МБ, скачивается один раз в `models/`).
Шумоподавление обрабатывает исходник один раз и кэширует результат: 10 минут записи — около 25 секунд на
процессоре. «Выключить» отключает всё, включая громкость (`lufs`) и лимитер: остаётся только монтаж.

Учтите: если запись тихая, нормализация до −16 LUFS поднимает её громкость, а вместе с ней и шум. Без
шумоподавления шум станет слышнее, чем в исходнике.

## Подключение к Claude Desktop (MCP)

В Claude Desktop: Settings → Developer → Edit Config, добавьте в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "voicer": {
      "command": "C:\\путь\\к\\Voicer\\.venv\\Scripts\\python.exe",
      "args": ["-m", "voicer", "mcp"]
    }
  }
}
```

Инструменты: `import_file`, `show`, `edit`, `undo`, `render_audio`, `export`, `stats`, `list_projects`.
Для длинных записей лучше импортировать через веб-интерфейс: распознавание может не уложиться в тайм-аут
MCP-вызова.

## Где что лежит

- `projects/<id>/`: исходник, `project.json` (транскрипт и правки), `out/` (результаты);
  `projects/example-3d/` — пример
- `models/`: модели Whisper и шумоподавления
- `AGENTS.md`, `CLAUDE.md`: инструкции для ИИ-агентов; `.claude/skills/voicer`, `.agents/skills/voicer`: скилл
  монтажа для Claude Code и Codex
