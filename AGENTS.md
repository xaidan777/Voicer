# Voicer — инструкции для ИИ-агента

Voicer — мост между пользователем и LLM для монтажа речи. Пользователь загружает аудио (mp3/ogg/wav/…) или
текст через веб-интерфейс (`start.bat` / `./start.sh`, http://127.0.0.1:8765) или просит тебя. Ты читаешь
транскрипт с пословными таймкодами, решаешь, что вырезать и какие паузы поправить, и применяешь правки
командами `voicer`. Пользователь сразу видит правки в открытом интерфейсе.

**Монтаж записей — по скиллу `voicer`**: `.claude/skills/voicer/SKILL.md` (Claude Code) и
`.agents/skills/voicer/SKILL.md` (Codex), содержимое одинаковое. Прочитай его перед любой работой с
проектами: там рабочий цикл, команды правок и правила, что резать.

- Команды: `.venv/Scripts/python.exe -m voicer …` (Windows) или `.venv/bin/python -m voicer …`.
- Не правь `projects/*/project.json` руками: только через `voicer edit`, иначе ломается отмена и история.
- `projects/example-3d/` — пример: 11 минут из 27 голосовых, дубли и паразиты уже вычеркнуты.

## Установка

`start.bat` при первом запуске вызывает `install.bat`: ставит uv, Python 3.11 и библиотеки из
`requirements-win.txt` (проверенный набор, с `--no-deps`), torch для процессора и, если есть видеокарта NVIDIA,
CUDA-библиотеки из `requirements-gpu.txt`. На macOS/Linux то же делает `install.sh` (не проверялся).
Модели скачиваются при первом использовании в `models/`.

deepfilternet 0.5.6 формально требует numpy<2, но работает с numpy 2.x: он ставится с `--no-deps`.
Не ставить его с зависимостями: uv попытается понизить numpy, а это ломается, пока запущен `start.bat`.

## Устройство

- `voicer/transcribe.py`: faster-whisper (GPU: large-v3-turbo, CPU: small), пословные таймкоды; подсказка
  для Whisper, чтобы он записывал «э-э» (выключается `--no-filler-prompt`).
- `voicer/analyze.py`: уточнение границ слов по энергии и поиск нераспознанных звуков; `stt_fillers` —
  проверка заминок распознавателем. Отдельную модель выравнивания не ставить: хватает имеющегося STT.
- `voicer/pack.py`: пак (склейка нескольких записей) и поиск дублей по отдельно распознанным фразам.
- `voicer/ops.py`: язык правок; `voicer/render.py`: план монтажа, кроссфейды, LUFS, txt/srt.
- `voicer/enhance.py`: шумоподавление DeepFilterNet3 (кэш `projects/<id>/cache/`); `voicer/dsp.py`: гул,
  срез низов, подавление эха (метод Лебара), гейт, де-эссер, левелер, компрессор, лимитер, громкость.
  Настройки обработки подобраны по эталону Auphonic: хвосты эха после слов и паузы должны быть не громче
  эталона, а тихие звуки речи не должны пропадать.
- `voicer/view.py`: текстовое представление для LLM; `voicer/web/`: интерфейс; `voicer/mcp_server.py`: MCP.
- Проекты: `projects/<id>/` (`project.json`, `source.*`, `undo.json`, `peaks.json`, `out/`). Модели: `models/`.
- Подробное описание интерфейса и настроек для людей: `docs/guide.md`.
